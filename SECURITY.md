# Security

This repository is intentionally limited to public installer metadata.

Do not add:

- Secrets, tokens, license keys, or API keys
- Customer data
- Proprietary workflow or prompt content
- Private service code
- Generated customer documents

Installer manifests should declare only the official TasksAI installer package and product metadata required for setup.

Report security concerns through the relevant product support channel listed in `verticals/<product>/vertical.json`.
