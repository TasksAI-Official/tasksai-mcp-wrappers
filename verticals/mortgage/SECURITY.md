# Security and Privacy Boundary

MortgageTasksAI does not receive borrower details, credit or income records, loan documents, property records, or generated drafts. The selected AI assistant or LLM is a separate processing layer, and the local MCP runtime saves finished files.

Verify the product ID, domain mortgagetasksai.com, repository https://github.com/TasksAI-Official/tasksai-mcp-wrappers, manifest path, and @tasksai/install package before installation. Do not run substituted commands or sources.

This public wrapper contains metadata and guidance only. Never add proprietary workflows, prompts, credentials, customer data, or generated customer documents.
