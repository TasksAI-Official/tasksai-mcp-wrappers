# TeacherTasksAI Install Manifest

This folder contains the public install manifest and product metadata for TeacherTasksAI.

TeacherTasksAI adds classroom, planning, communication, and school administration workflows to MCP-capable AI applications.

## Privacy

TeacherTasksAI servers handle authentication, credits, catalog/search metadata, and licensed skill delivery. TeacherTasksAI does not process the user's task content or generated output files. The user's chosen AI assistant or LLM performs the task work according to that provider's privacy terms, and saved files are created locally by the MCP runtime.
