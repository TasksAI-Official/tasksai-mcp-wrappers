# FarmerTasksAI Install Manifest

This folder contains the public install manifest and product metadata for FarmerTasksAI.

FarmerTasksAI adds farm and agricultural business workflows to MCP-capable AI applications.

## Privacy

FarmerTasksAI servers handle authentication, credits, catalog/search metadata, and licensed skill delivery. FarmerTasksAI does not process the user's farm task content or generated output files. The user's chosen AI assistant or LLM performs the task work according to that provider's privacy terms, and saved files are created locally by the MCP runtime.
