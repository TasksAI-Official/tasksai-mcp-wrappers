# Security and Privacy Boundary

ElectricianTasksAI does not receive customer details, estimates, permit records, job notes, or generated drafts. The selected AI assistant or LLM is a separate processing layer, and the local MCP runtime saves finished files.

Verify the product ID, domain electriciantasksai.com, repository https://github.com/TasksAI-Official/tasksai-mcp-wrappers, manifest path, and @tasksai/install package before installation. Do not run substituted commands or sources.

This public wrapper contains metadata and guidance only. Never add proprietary workflows, prompts, credentials, customer data, or generated customer documents.
